
## 9. 후속 확장 — 휴리스틱·c2·CSP 및 자동 회귀 검사

2026-11-18, Windows 11/Node.js 24.22.3. 최초 400판 검사에 이어 기존 명세 기반 엔진을 변경하지 않고 입력·비교 어댑터 expand-check.mjs를 추가했다.
이 어댑터는 기존 구현을 읽은 통합 검증 맥락에서 작성됐으며 env/agents를 import하지 않는다.
최초 독립 구현과 후속 확장의 작성 이력을 구분하고, 후속 작업 전체를 새로운 클린룸 구현이라고 주장하지 않는다.
엔진 SHA-256: 94d2dc30d22df7d3667dd7994b34dd9a79516f0f0419590e9eca52003ee25206.

| 로그 묶음 | 파일 | 재생 판수 | 지표 불일치 | 입력 해시 없음 |
| --- | ---: | ---: | ---: | ---: |
| Greedy 기존 최종: 최대거리/c1, MST/c1·c2 | 3 | 300 | 0 | 300 |
| A* 기존 최종: L1/L2 휴리스틱·c1/c2 및 h=0 | 10 | 1,000 | 0 | 1,000 |
| 재계획 기존 최종: L2 MST/c1 3모드 | 3 | 300 | 0 | 300 |
| CSP 후보: L0~L3 및 L2 FC/재계획 추가 설정 | 7 | 430 | 0 | 0 |
| 최신 Greedy·A* 재계획 4조건 | 4 | 400 | 0 | 0 |
| 정식 CSP L2 never | 1 | 100 | 0 | 0 |
| 합계 | 28 | 2,530 | 0 | 1,600 |

서로 다른 입력 시나리오는 L0~L3 시드 0~99의 400개다. 2,530판은 파일별 재생 기록 수이며 고유 시드 수가 아니다.
같은 시나리오·동일 조건의 다른 커밋 재실행을 섞어 평균을 내지 않는다.
L0/L3 독립 엔진 재생은 이번 묶음 중 CSP 후보에 해당하며 모든 알고리즘에서 L0/L3를 새로 실행한 것은 아니다.
CSP는 후보와 정식 로그를 합쳐 530기록이며 530개의 고유 시나리오가 아니다.

총비용·평균배달시간·성공·항의 발생·초과의 다섯 지표에 추가로 종료 시각·잘못된 행동 수·항의초과율까지 대조했다.
c2 로그의 평균배달시간은 주문별 완료 시각에서 재계산한 값이다. 탐색 노드수·계산시간·휴리스틱 허용성·알고리즘 최적성을 이 재생으로 새로 증명한 것은 아니다.
타임아웃·중간에 끊긴 행동열은 이 어댑터의 지원 범위가 아니며 성공으로 처리하지 않고 검사 실패로 보고한다.
원본 JSONL은 수정하지 않았다. 비교 기준은 정책4, finish, 새 항의는 앞 마감 다음 틱부터 허용이다.

초기 어댑터 검사에서 L0/L1 CSP 200판의 해시가 맞지 않았으나 원인은 JS가 q=0.0을 0으로 직렬화하는 차이였다.
스키마상 q는 Python float이므로 0.0 표기를 복원해 해시를 재계산했다. 해시 비교를 끄거나 로그를 변경하지 않았고 이후 해당 200판도 해시와 점수가 일치했다.
q=0·0.03의 직렬화와 손계산 정답, 잘못된 점수·해시·행동·프리셋·미완료·종료 후 행동을 검출하는 어댑터 회귀 검사를 추가했다.
과거 1,600판에는 해시가 없으므로 현재 시나리오로 점수가 일치해도 과거 입력 동일성을 완전히 입증하지 못한다.

CI에는 기존 Python 작업을 유지하고 reference-regression 작업을 추가했다.
Node 24에서 hand-check, horizon-check, complaint-deadline-check, expand-check.test 네 검사를 실행한다.
원본 로그는 Git에 없으므로 2,530판 전체 재생을 CI가 수행하는 것은 아니다. 전체 재생은 로컬 증거로 구분한다.
GitHub 원격 실행 결과는 해당 커밋의 Actions 기록을 별도로 따른다.

재현:
```powershell
node verify/delivery-reference/expand-check.test.mjs
node verify/delivery-reference/expand-check.mjs --out logs/runs/expanded-reference.json logs/greedy_final logs/astar_final logs/replanning_final logs/runs/20261117/b/csp_candidate logs/runs/20261118/jinsu_current_v3
```
